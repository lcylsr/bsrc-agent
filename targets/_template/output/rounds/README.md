# 轮次档案（rounds/）— 阅读与写入说明

> **结构**: `2026-MM-DD.md` 按日一卷。每段 = 一个轮次/补充记录，带溯源注释 `<!-- @<追加时间> [cat|py|edit|disk] -->`。
> **写入**: 新进展 → 追加到 `output/rounds/<当日日期>.md`，并在 `_STATE.md` 更新一行摘要 + 「最后更新」时间戳。**禁止**把长叙事直接写进 `_STATE.md`（_STATE 只存可秒读的工作状态）。
> **定位**: 从 `_STATE.md`「轮次档案索引」按日期定位卷文件。轮次段格式：`## P-<NNN> <主题>（<日期>）`。
